## Routing and benchmark decision

The selected option is **explicit provisional pins** for 6.1 Sol and Terra, with no default route, score-band change, class prior, fallback, or automatic migration. The 21–50 band remains on GPT-5.6 Terra until a paired evaluation runs identical repository coding and review cases at both models' medium effort, with verified returned model ids, correctness grades, retry and reissue counts, token usage, and median and tail cost/latency. A comparable 6 Sol versus 6.1 Sol medium/xhigh cohort is required before promoting the Sol migration. Vendor claims in release posts and existing Cost Frontier benchmark rows are attributed evidence, not those local cohorts. The current-model website projection includes 6.1 Terra and retains Carbon only as a restricted announcement.

`gpt-live-1` is a realtime speech model in the [OpenAI model list](https://developers.openai.com/api/docs/models). This catalogue's `TokenUsage` and routes represent text input/output with optional text prompt caching, so audio-minutes, voice/session charges and realtime semantics are outside its pricing domain; it is recorded here but not added as a false text tariff.
