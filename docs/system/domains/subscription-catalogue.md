# Subscription catalogue

As of 2026-11-02. Prices are USD before tax. A blank numeric limit means the provider did not publish an absolute amount in the cited source. Annual commitments, per-seat charges, credits and metered API usage are stated separately. Model lists are candidate inventory; the live login, client version, rollout and workspace policy still decide access.

The [machine catalogue](../../../src/TokenEconomy/catalog/subscription-plans.json) carries source IDs for every plan. Those IDs resolve in the [TE-61 source register](../../cli-integration-domain/source-register.json). The [TE-61 terms analysis](../../cli-integration-domain/cli-integration-domain.md#auth-documentation) explains the distinct scripting, self-built orchestration and third-party product contexts. `documented`, `conditional`, `restricted`, `ambiguous` and `unknown` below describe published context, not a legal conclusion.

## Login API

`SubscriptionCatalogue.Default.ResolveOpenAiLogin(loginId, verifiedClaims, observedAtUtc, requiredModelIds)` reads `chatgpt_plan_type` from a claim dictionary supplied by the authenticated caller. It never parses or trusts a raw token. For a login authenticated with an OpenAI API key, call `ResolveLogin("openai", loginId, "openai-api", observedAtUtc, requiredModelIds)`; this identifies the catalogued API plan while model access stays account-specific (`Unknown`). The result gives the active plan ID and a `Candidate`, `Unavailable`, or `Unknown` state for each requested model. `AssessPlanChange(previous, current)` warns on candidate-to-unavailable regressions for the same login. `Unavailable` means absent from the catalogued plan candidates, not proof that the provider will reject a call. A candidate is not proof of live access; callers should also use a live model discovery or execution probe. Unknown plans and API-key model grants remain unknown.

## Operator evidence

The [subscription observation log](../../../src/TokenEconomy/catalog/subscription-observations.json) records dated model probes, quota resets, burn rates and the Claude five-hour/weekly ratio, each with its method. The [token-per-percentage-point log](../../../src/TokenEconomy/catalog/quota-token-observations.json) has separate uncached input, cached input, output and reasoning fields, plus completeness and method. Its output field includes reasoning when reported that way; `reasoningTokensApprox: null` means it was not separately measured. The October 20 total is incomplete while runs were in flight. These measurements do not change the published plan limits.

Eligible ChatGPT Pro and Business subscriptions can [claim API credits](https://developers.openai.com/api/docs/guides/chatgpt-api-credits) through a linked API organization (announced 2026-10-28). Pro tiers grant $100, $200 or $500 monthly; Business grants $20 per paid Standard seat or $100 per paid Premium seat, pooled up to $500 monthly per workspace. Eligibility and activation are account-specific. These API credits do not raise signed-in Codex limits and are not subtracted from catalogue list prices.
