The `agy models` listing supplied by the operator on 2026-10-16 (agy 1.4.0) is observation of the suffixed Gemini ids. The catalog keeps canonical base ids and resolves the observed low/medium/high suffixes. Although `agy --effort` accepts xhigh/max flags generally, the model pages confirm only low/medium/high for these two models; those other levels are rejected by routing knowledge.

The Standard API tariffs are list-price estimates for direct API requests. They are not a claim about Antigravity subscription charges. Calendar days are normalized to 00:00 UTC; the vendors do not publish exact intraday tariff cutovers. Future entries record announced prices and remain dated so they cannot apply early. Missing cache-write prices were left null; no missing tariff was set to zero.

A prompt-size tier now applies to Haiku 5.5 and the previously documented GPT-6.1 Sol 272K threshold. `TokenUsage.PromptTokens` gives the full per-request prompt length. Without it, a tiered `ComputeCost` returns `AmbiguousPromptSize` and a null total. The efficiency matrix's synthetic aggregate workload declares a representative 20K per-request prompt; its 1M total input represents many requests at that same tier. The website price history publishes both Haiku tiers.
